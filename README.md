# 🖱️ GRControl — Remote PC Control

**GRControl** — это приложение для удаленного управления компьютером на Windows с Android-смартфона через локальную сеть (Wi-Fi). 

Проект состоит из серверной части на Python (WebSocket + PyAutoGUI) и клиентского мобильного приложения на Flutter.

---

## 🚀 Как пользоваться (Быстрый старт)

### ⚠️ Важное примечание:
> **Смартфон и ПК должны находиться в ОДНОЙ локальной сети** (например, подключены к одному домашнему Wi-Fi роутеру).

---

### Шаг 1. Запуск сервера на ПК

1. Перейдите в раздел [Releases](https://github.com/Donnyu/GRcontrolgit/releases) и скачайте файл **`GRemoteServer.exe`**.
2. Запустите `GRemoteServer.exe`.
   * *Если Windows SmartScreen или Брандмауэр спросят разрешение — нажмите **«Разрешить доступ»**.*
3. Узнайте локальный IP-адрес вашего ПК в сети:
   * Нажмите `Win + R`, введите `cmd` и нажмите Enter.
   * Введите команду `ipconfig`.
   * Найдите строку **IPv4-адрес** (обычно выглядит как `192.168.X.X`).

---

### Шаг 2. Установка и настройка приложения на Android

1. В разделе [Releases](https://github.com/Donnyu/GRcontrolgit/releases) скачайте **`app-arm64-v8a-release.apk`** на ваш смартфон.
2. Установите APK-файл на телефон.
3. Откройте приложение **GR Control**.
4. Введите IP-адрес вашего ПК (например, `192.168.1.50`).
5. Выберите нужный режим (Управление экраном или Быстрые действия).

---

## 🛠️ Возможности
- 📺 Передача рабочего стола ПК в реальном времени.
- 🖱️ Управление курсором и кликами прямо с сенсорного экрана.
- ⚡ Быстрые команды управления питанием (Shutdown, Restart, Lock).
- 🔌 Подключение по высокоскоростному протоколу WebSocket.
